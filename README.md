
# Aryan Dwivedi — Responsive Portfolio Website

A modern, responsive personal portfolio website built with HTML5,
CSS3, and vanilla JavaScript.

## Features

- Home section with introduction and social links
- About section with profile information
- Technical skills cards and skill indicators
- Featured project cards
- Education timeline
- Experience and project-work sections
- Contact form with client-side validation
- Responsive mobile navigation
- Active navigation highlighting
- Back-to-top button
- Current year displayed automatically
- Keyboard focus indicators
- Reduced-motion support
- No front-end framework or external image dependency

## How to Run

1. Download or clone this project.
2. Open the project folder in Visual Studio Code.
3. Ensure all four files are in the same directory.
4. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code for
convenient local development.

## Customize Your Portfolio

Update the following information in `index.html`:

- Name, introduction, and professional title
- Location and About section
- Technical skills and proficiency indicators
- Project titles, descriptions, and repository links
- Education and experience details
- Email address
- GitHub and LinkedIn profile URLs

Replace the sample project links with links to each actual
GitHub repository or live website.

## Contact Form Notice

The contact form validates input in the browser. It does not
send or save messages.

To receive real messages, connect the form to a secure backend
or a suitable form-processing service. Do not put private API
keys or credentials in client-side JavaScript.

## Important Notes

- Skill percentages are illustrative and should reflect your
  actual proficiency.
- Verify all personal, education, and experience details.
- Update the homepage and social links before publishing.
- Client-side validation does not replace server-side validation.
